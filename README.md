# Delight Bridge 프론트엔드 데모

백엔드 없이 화면과 주요 사용자 흐름을 시연하기 위한 독립 React/Vite 프로젝트입니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 정적 파일:

```bash
npm run build
npm run preview
```

## 데모 범위

- 홈, 뉴스, 사역 현장, 회복 간증, 봉사활동 화면
- 일반 사용자, 담당 팀장, 관리자 가상 로그인
- 마이페이지와 담당 팀 신청자 화면
- 관리자 회원·봉사활동·신청·뉴스·사역팀 화면
- 브라우저 메모리 안에서만 반영되는 샘플 CRUD
- 로컬 이미지 미리보기와 샘플 보고서 다운로드

로그인 창 하단의 `일반 사용자`, `업로더`, `관리자` 버튼으로 역할을 바꿀 수 있습니다. 로그인 역할은 현재 브라우저 탭의 `sessionStorage`에만 보관됩니다.

## 데이터 정책

- 서버, 데이터베이스, OAuth, 쿠키 세션을 사용하지 않습니다.
- 실제 회원·신청자·연락처 데이터가 포함되어 있지 않습니다.
- 모든 샘플 변경은 새로고침하면 초기화됩니다.
- 외부로 전달할 때는 `dist/` 폴더만 정적 호스팅해도 됩니다.
